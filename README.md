# 🎲 Угадай число

Консольная игра «Угадай число» на Go, где нужно угадать случайное
число за ограниченное число попыток.

## Возможности
- 3 режима сложности (Easy 1-50 / 15 попыток, Medium 1-100 / 10, Hard 1-200 / 5)
- Подсказки «Горячо / Тепло / Холодно» (близко ли число)
- Цветной вывод в консоли (пакет `fatih/color`)
- История игр сохраняется в `results.json`
- Возможность сыграть ещё раз после проигрыша

## Запуск
```bash
go run ./cmd/app
